Gaazeon's Blog is a public technical blog. All public content is free to read.

## Free Access

- Reading articles: free
- RSS feeds: free
- Sitemap files: free
- Markdown discovery files: free
- OpenAPI discovery description: free
- Pagefind static search metadata: free

## Unsupported Access Models

The site does not provide paid plans, user accounts, OAuth login, API keys, private dashboards, checkout flows, or write APIs.

## Agent Guidance

AI agents can fetch public static resources without authentication. Prefer [llms.txt](/llms.txt), [full LLM context](/llms-full.txt), [agent instructions](/agents.md), [Markdown index](/index.md), [OpenAPI description](/openapi.json), RSS feeds, and sitemap files.

Use the [contact page](/en/contact/) for author contact.
