# 🚀 Blog Milestones

Documenting key milestones in Gaazeon blog's technical evolution.

---

## 📅 Development Journey

### **2023 & Earlier - Hexo Era**
- Blog created on GitHub platform
- Used Hexo static blog generator
- Basic Markdown blogging functionality

### **2024 - Astro Migration**
- **Early 2024**: Migrated from Hexo to Astro.js
- **Platform Change**: Moved from GitHub Pages to Vercel
- **Tech Stack Upgrade**:
  - Framework: Hexo → Astro 5.x
  - Styling: Traditional CSS → TailwindCSS v4
  - Language: JavaScript → TypeScript
  - Search: Upgraded to Pagefind static search
- **Feature Enhancements**:
  - Dark/light theme toggle
  - Responsive design optimization
  - Auto-generated OG images
  - Mermaid diagram support
  - RSS subscription functionality

### **October 2025 - Internationalization**
- **Multi-language Support**: Implemented Chinese/English bilingual experience
- **Localized Routing**: URL routes support language prefixes
- **Content Management**:
  - Chinese articles: `/blog/` path
  - English articles: `/en/blog/` path
- **Navigation Optimization**: Language switcher supports page-to-translation mapping
- **SEO Enhancement**: Search engine optimization for different languages

## 🔮 Technical Evolution

### Architecture Choices
- **Performance First**: Astro static generation, zero runtime overhead
- **Developer Experience**: TypeScript type safety with hot reload development
- **Maintainability**: Component-based architecture with modular design
- **Internationalization**: Astro i18n support with multi-language routing

- **Foundation**: AstroPaper theme as base
