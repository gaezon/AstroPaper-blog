# 隐私政策

Gaazeon 博客是一个公开技术博客。网站内容可匿名阅读，不提供用户账号、付费订阅、私有 API 或登录系统。

## 访问统计

本站在生产环境中使用自托管 Umami 做基础访问统计，用于了解页面访问量和改进内容结构。统计不需要你注册账号，也不用于广告定向。

## 评论

部分文章可能加载评论组件。评论服务由本站配置的评论域名提供；如果你主动发表评论，评论内容、昵称和你提交的信息会被用于展示评论和后续交流。

## 搜索

站内搜索基于静态 Pagefind 索引运行。搜索主要在浏览器本地完成，不需要登录。

## 外部链接

文章可能链接到第三方网站。访问第三方网站时，请以对方网站的隐私政策为准。

## 联系

如需询问隐私相关问题，可以通过 [联系页面](/contact/) 找到邮箱。
