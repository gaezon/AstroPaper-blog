# 🚀 博客里程碑

记录 Gaazeon 博客技术演进的重要节点。

---

## 📅 发展历程

### **2023年及之前 - Hexo 时代**
- 博客创建于 GitHub 平台
- 使用 Hexo 静态博客生成器
- 基础的 Markdown 博客功能

### **2024年 - Astro 迁移**
- **年初**：从 Hexo 迁移到 Astro.js
- **部署平台**：从 GitHub Pages 迁移到 Vercel
- **技术栈升级**：
  - 框架：Hexo → Astro 5.x
  - 样式：传统 CSS → TailwindCSS v4
  - 语言：JavaScript → TypeScript
  - 搜索：升级为 Pagefind 静态搜索
- **功能增强**：
  - 深色/浅色主题切换
  - 响应式设计优化
  - OG 图片自动生成
  - Mermaid 图表支持
  - RSS 订阅功能

### **2025年10月 - 国际化改造**
- **多语言支持**：实现中英文双语
- **路由本地化**：URL 路由支持语言前缀
- **内容管理**：
  - 中文文章：`/blog/` 路径
  - 英文文章：`/en/blog/` 路径
- **导航优化**：语言切换器支持页面对应翻译
- **SEO 增强**：针对不同语言的搜索引擎优化

## 🎯 当前特性

### 核心功能
- ✅ **多语言支持**：中英文完整双语体验
- ✅ **静态搜索**：基于 Pagefind 的全文搜索
- ✅ **主题系统**：深色/浅色/跟随系统
- ✅ **响应式设计**：移动端优先设计
- ✅ **SEO 优化**：完整的 meta 标签和结构化数据
- ✅ **隐私保护**：Cookie 同意管理和 GDPR 合规

### 技术特性
- ⚡ **极速加载**：静态站点生成，CDN 加速
- 🎨 **现代设计**：TailwindCSS v4 原子化样式
- 🔍 **智能搜索**：客户端搜索，无需服务器
- 📱 **完美适配**：桌面端和移动端一致性体验

## 🔮 技术演进

### 架构选择
- **性能优先**：Astro 静态生成，零运行时开销
- **开发体验**：TypeScript 类型安全，热重载开发
- **可维护性**：组件化架构，模块化设计
- **国际化**：Astro i18n 支持，多语言路由

### 从模板到定制
- **基础框架**：AstroPaper 主题
- **深度定制**：根据需求调整功能和样式
- **本地化适配**：中文友好，完整的中英文支持
- **持续优化**：基于实际使用反馈不断改进
