# Contributing

This is a personal blog maintained by Gaazeon. Small, focused contributions are welcome, especially typo fixes, bug fixes, accessibility or i18n improvements, and documentation updates.

Before opening an issue or pull request:

- Keep the change focused and explain what changed and why.
- Do not commit secrets, local environment files, generated output, or test artifacts.
- For article or bilingual-content changes, read [WRITING.md](WRITING.md).

For larger changes, open an issue first. Feature direction and deployment remain maintainer-controlled.

For security vulnerabilities, see [SECURITY.md](SECURITY.md).
