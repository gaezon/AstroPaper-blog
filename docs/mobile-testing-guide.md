# 📱 移动端语言切换器测试指南

## 🧪 如何测试

### 方法 1: Chrome DevTools（推荐）

1. **打开开发者工具**
   - 按 `F12` 或 `Cmd+Option+I` (Mac)
   - 或右键 → 检查

2. **切换到设备模式**
   - 按 `Cmd+Shift+M` (Mac) 或 `Ctrl+Shift+M` (Windows)
   - 或点击工具栏的设备图标 📱

3. **选择设备**
   - iPhone SE (320px) - 最小屏幕
   - iPhone 12/13 (390px) - 标准
   - iPhone 14 Pro Max (430px) - 大屏
   - iPad Mini (768px) - 平板

4. **测试步骤**
   ```
   ✅ 点击右上角汉堡菜单图标（三横线）
   ✅ 菜单展开，查看语言切换器
   ✅ 点击 "EN" 切换到英文
   ✅ 点击 "中" 切换到中文
   ✅ 确认当前语言有蓝色高亮
   ✅ 确认按钮大小适合手指点击
   ```

### 方法 2: 实际设备测试

1. **在手机上访问**
   ```
   http://localhost:4321/
   ```
   或使用局域网 IP（需要在启动时加 --host 参数）

2. **测试流程**
   - 点击汉堡菜单
   - 测试语言切换
   - 确认触摸反馈
   - 确认页面跳转

## ✅ 检查清单

### 视觉检查
- [ ] 语言切换器占满整行宽度（移动端）
- [ ] 内容居中对齐
- [ ] 地球图标清晰可见
- [ ] "中" 和 "EN" 之间有斜杠分隔
- [ ] 当前语言有蓝色文字和背景高亮
- [ ] 字体大小适中，易于阅读
- [ ] 与其他菜单项间距一致

### 交互检查
- [ ] 点击"中"能切换到中文页面
- [ ] 点击"EN"能切换到英文页面
- [ ] 触摸区域足够大（不容易误触）
- [ ] 点击后菜单自动关闭（可选）
- [ ] 页面正确跳转到对应语言版本

### 响应式检查

### 主题检查
- [ ] 浅色模式 - 颜色正常
- [ ] 深色模式 - 颜色正常

## 💡 Pro Tips

### Tip 1: 快速切换设备

- 点击设备下拉菜单
