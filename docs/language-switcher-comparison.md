# 语言切换器变体对比

## 三种变体快速对比

| 特性 | Dropdown 下拉 | Compact 紧凑 | Toggle 切换 |
|------|-------------|-------------|------------|
| **适用场景** | 桌面端、多语言 | 导航栏、移动端 | 双语网站、侧边栏 |
| **空间占用** | 中等 | 最小 | 较大 |
| **语言数量** | 3+ 种语言 | 2-3 种语言 | 2 种语言 |
| **视觉效果** | 专业、优雅 | 简洁、现代 | 直观、清晰 |
| **交互方式** | 点击展开 | 直接点击 | 直接点击 |
| **用户体验** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| **SEO 友好** | ✅ | ✅ | ✅ |
| **无障碍** | ✅ | ✅ | ✅ |
| **移动端** | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |

## 视觉预览

### Dropdown 下拉菜单
```
┌──────────────────┐
│ 🌐 简体中文  ▼  │ ← 按钮
└──────────────────┘
        ↓ 点击展开
┌──────────────────┐
│ 🌐 简体中文  ▲  │
├──────────────────┤
│ 简体中文      ✓ │ ← 当前语言（蓝色高亮）
│ English         │
└──────────────────┘
```

### Compact 紧凑模式
```
┌────────────┐
│ 🌐 中 / EN │ ← 一行显示，中文高亮
└────────────┘
```

### Toggle 切换按钮
```
┌─────┐  ┌─────┐
│ 中文 │  │ EN  │ ← 中文按钮蓝色背景
└─────┘  └─────┘
```

## 推荐使用场景

### 1. Header 导航栏（当前实现）
**推荐**: `compact` 紧凑模式

**原因**:
- 节省导航栏空间
- 移动端友好
- 与主题切换按钮一致的视觉风格

### 2. Footer 页脚
**推荐**: `dropdown` 下拉菜单

**原因**:
- 页脚空间充足
- 可以显示完整的语言名称
- 更专业的视觉效果

### 3. 文章页侧边栏
**推荐**: `toggle` 切换按钮

**原因**:
- 侧边栏垂直空间充足
- 直观的语言切换
- 不需要额外的点击展开

## 当前实现

项目当前使用 **compact 紧凑模式**：

```astro
<!-- src/components/Header.astro -->
<LanguageSwitcher variant="compact" override={switchOverride} />
```

**优点**:
- ✅ 完美适配移动端
- ✅ 与导航栏其他图标风格一致
- ✅ 占用最小空间
- ✅ 一目了然的当前语言

## 如何切换变体

只需修改 `variant` 属性：

```astro
<!-- 改为下拉菜单 -->
<LanguageSwitcher variant="dropdown" />

<!-- 改为切换按钮 -->
<LanguageSwitcher variant="toggle" />

<!-- 改回紧凑模式 -->
<LanguageSwitcher variant="compact" />
```

## 样式定制

所有变体都使用主题的 CSS 变量，会自动适配：
- 浅色/深色模式
- 主题色调整
- 自定义字体

需要进一步定制可以添加自定义类：

```astro
<LanguageSwitcher 
  variant="compact" 
  class="my-custom-lang-switch"
/>
```

```css
.my-custom-lang-switch {
  /* 自定义样式 */
}
```
