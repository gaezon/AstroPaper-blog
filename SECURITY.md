# Security Policy

## Supported versions

Only the latest version on the default `main` branch is actively supported.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue or pull request. Send a private report to [gaazeon@gaazeon.com](mailto:gaazeon@gaazeon.com) with:

- A clear description of the issue and its potential impact
- Steps or a minimal example that reproduces it
- Any relevant logs, screenshots, or suggested mitigation

Please allow time for the issue to be investigated and fixed before sharing details publicly.
